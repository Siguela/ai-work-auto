# 需求输入模板（简版）

使用方式：

1. 每次有新需求时，复制本文件到对应需求文件夹
2. 将文件重命名为更明确的名字，例如 `需求输入.md`
3. 按下面格式填写
4. 填完后直接让我读取这个文件

---

板块：

需求名称：

业务背景：

报表展示表头：

字段口径：

想看的粒度：

需要的筛选项：

补充说明：

---

填写示例：

板块：海外学科

需求名称：线下作业批改看板

业务背景：希望按老师和小组观察线下作业批改完成情况，识别积压和异常。

报表展示表头：
- 日期
- 老师团队
- 老师小组
- 老师姓名
- 待批改份数
- 已批改份数
- 批改完成率

字段口径：
- 待批改份数：进入批改池但截至统计时点未完成批改的作业数
- 已批改份数：截至统计时点已完成批改的作业数
- 批改完成率：已批改份数 / 应批改份数

想看的粒度：天 / 老师 / 小组

需要的筛选项：
- 开始日期
- 结束日期
- 老师团队
- 老师小组
- 老师姓名

补充说明：
- 只看海外学科正课
- 排除测试数据
- 口径尽量对齐现有作业相关报表
